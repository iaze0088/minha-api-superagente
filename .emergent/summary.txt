<product_requirements>
The CYBERTV Suporte application is a multi-tenant live chat system designed for Admin, Agent, and Client users. Its core problem statement revolved around providing real-time chat with file uploads, ticket management, configurable messages, and PWA support with custom branding. A critical requirement was a robust multi-tenant reseller system, allowing each reseller a custom domain, an independent admin-like panel, hierarchical sub-reseller creation, and isolated data.

Implementation so far includes:
- Agent Dashboard UI improvements: Displaying new message counts, limiting visible tickets to 7 with scroll, showing a 20-character message preview, and a Copy PIX Key button.
- Strict content validation for messages (CPF/email/WhatsApp/random PIX).
- A configurable PIX key in the Admin panel.
- A weekly WhatsApp pop-up for clients.
- A comprehensive AI integration panel in Admin with multi-LLM support and access to client credentials.
- A full multi-agent system, allowing creation of multiple AI agents per reseller.
- Department management (Suporte, Vendas, Teste Grátis) with intelligent routing: clients select via buttons, or unaddressed messages timeout to Suporte.
- Agent permissions are now linked to specific departments.
