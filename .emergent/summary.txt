-   **Three distinct panels:** Admin (management), Agent (customer support), and Client (end-user chat).
-   **Real-time chat** with WebSockets, including file uploads (images, videos, audio, documents).
-   **Ticket management** with queues (Em Espera, Atendendo, Finalizadas).
-   **Configurable messages**: Quick replies, auto-response rules.
-   **Admin features**: Agent CRUD, quick block messages, auto-reply rules, app tutorials, notices.
-   **Agent features**: View tickets by status, chat with clients, pin client credentials, reset client PIN, use quick messages.
-   **Client features**: Chat with agents, send media, view notices, change PIN, update profile photo.
-   **Modern UI/UX** with dark mode (initially), glass-morphism effects, and micro-animations.
-   **PWA (Progressive Web App)** for Android, installable from the website with a custom CyberTV logo and audio notifications for new messages.
-   **Persistent login** for Client and Agent, with automatic logout only on manual logout or simultaneous login from another device.
-   **Custom domain support** for the main application and a robust **reseller management system**. Each reseller should have an independent admin-like panel, customizable configurations, and their own custom domain (e.g., ), with updates from the main admin propagating to reseller panels.
